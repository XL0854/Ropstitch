# 方案 2 (组合 B): 跨图交叉注意力 + 卷积式拓扑网格头 (Combo B)

## 1. 架构设计与动机
前两阶段（M2 状态反馈、M3 残差精修与 SSIM 模块）的实验明确揭示了原版 RopStitch 的核心天花板：
* **原版基线缺陷**: TPS 回归头将 `[B, 128, 4, 4]` 特征图用 `Flatten` 展平为 2048 维向量，再用全连接层（Dense Linear）强行拟合 338 个网格点坐标，**彻底破坏了 2D 图像局部拓扑与几何邻域信息**，且双图缺乏深层上下文关联交互。
* **组合 B (Combo B) 核心创新**:
  1. **跨图双向交叉注意力 (Cross-Attention Matcher)**: 在特征对齐层引入双向 Query-Key-Value 交互，让图 1 主动感知图 2 的对应特征，解决弱纹理与大视差匹配难题。
  2. **全卷积网格预测头 (ConvMeshHead)**: 彻底铲除 `Flatten + Linear`，采用纯 2D 残差卷积与自适应空间投影（`AdaptiveAvgPool2d` 到 $13 \times 13$），直接预测形状为 `[B, 13, 13, 2]` 的顶点形变，完整保留二维空间拓扑结构。
  3. **分层学习率解冻端到端微调**: 解冻配准主干网络的 `active_resnet_backbone`，采用差异化学习率（Backbone 7.5e-6, MeshHead 1.5e-4）进行联合优化。

## 4. 深度技术复盘与科学发现

### 为什么组合 B 表现随轮次降低 (Ep05 > Ep10 > Ep15)？
1. **网格自由度过高与正则化博弈**:
   原版基线使用全连接层虽然破坏了局部性，但也强行施加了高度刚性的隐式约束。全卷积头 `ConvMeshHead` 给予了每个网格点充分的局部自由度，在缺乏真值监督（无监督光度损失）下，模型为了追求重叠区域像素的微小拟合，会使边界网格产生微小畸变，随后触发二次方/指数级的几何折叠惩罚（`Geom Loss` 在后期激增至数万），反向梯度污染了骨干网络。
2. **“从零重构” 与 “即插即用残差” 的收敛代价差异**:
   - **M3 (组合 A)**: 采用“基线网格 + TAPR 残差 $\Delta M$”的结构，基线提供了强大的初始几何骨架，残差仅作局部微调，因此稳定性极高（PSNR 达 25.24 dB）。
   - **组合 B**: 彻底推翻了基线的 TPS 回归头并从随机初始化开始训练，同时解冻了深层骨干。在无监督拼接任务中，从零学出平滑一致的全局网格通常需要数十万步预训练与极精细的几何约束退火。

## 5. 下一步优化策略建议
若要结合组合 B 的空间局部性优势与基线的高精度保底，可采取以下混合演进方案：
1. **残差式卷积网格头 (Residual ConvMeshHead)**: 保留基线 TPS 粗对齐，由 `ConvMeshHead` 输出局部网格微调偏移量 $\Delta M$，且通过 `tanh * max_delta` 严格限制形变量。
2. **两阶段训练机制**: 第一阶段仅训练 Cross-Attention 与网格头（冻结 ResNet），第二阶段再以极小学习率微调骨干。
